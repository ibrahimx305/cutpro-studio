# CutPro Studio

A full browser-based video editor — no installation, no uploads, no server. Everything runs 100% in the browser with vanilla JavaScript, the Canvas API and MediaRecorder.

## Features
- Multi-track timeline: drag, trim, split, duplicate and delete clips, with zoom
- Media uploads (video, audio, images) plus a built-in demo library
- Speed control (0.25x–4x), scale, rotate and position controls
- Brightness / contrast / saturation adjustments and 9 filter presets
- Transitions between clips
- Animated text, titles and subtitles; stickers
- Audio volume control and fades
- Auto captions from speech recognition, subtitles from text, and device-voice narration
- Chroma-key background removal and one-click enhance
- Undo / redo throughout
- Export in 480p, 720p, 1080p or 4K at 16:9, 9:16, 1:1 or 4:5 (MP4 where the browser supports it, WebM otherwise)
- Save and reopen projects as local `.cutpro.json` files

## Run it
Open `index.html` in a modern browser, or serve the folder with any static file server.

## Privacy
CutPro Studio makes no network calls and sends nothing to any external service — your media never leaves your device.
